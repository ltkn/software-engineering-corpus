Goal: Run TypeScript 7 alongside 6.0 during the transition without binary conflicts.
Wiring (package.json, verified against the 7.0 release notes):
{
  "devDependencies": {
    "@typescript/native": "npm:typescript@^7.0.2",
    "typescript": "npm:@typescript/typescript6@^6.0.2"
  }
}
Why: 7.0 ships tsc from the native package while API-dependent tooling keeps using 6.0's tsc6 and API; both compilers coexist until the 7.1 API lands.
Legacy: single typescript@5.x install where editor, CLI, and API all share one binary.
Verification: npx tsc --version reports 7.x; npx tsc6 --version reports 6.x; both type-check the same tree clean.

Goal: Explain why this repo compiles TS with no enums or parameter properties.
Why: Native Node 24 strips types without a compiler, and native type-stripping only accepts erasable syntax — anything that survives to runtime (enum objects, namespace values, parameter-property shorthand) needs the tsc step we are trying to skip. The `erasableSyntaxOnly` flag turns ts-to-js differences into a compile-time error instead of a runtime surprise.
snippet:
// ok for native stripping:
type Role = "admin" | "editor";
function canEdit(r: Role): boolean { return r !== "viewer"; }
// not ok: enum Role { Admin, Editor }
legacy/counter form: `npm run build && node dist/index.js` when the file could be `node --experimental-strip-types src/index.ts`.
verification: Run the entrypoint twice — `node --experimental-strip-types` and `tsc` output — and diff the resulting values for parity; the test suite covers both paths in CI.

Goal: Speed up a monorepo type-check without losing project-reference boundaries.
Why: TS 7 runs checks in parallel by default on multi-core hosts; the experimental flags expose the knobs. Splitting the check by project reference keeps incremental state correct per project so a one-package change does not re-check the tree.
snippet:
{
  "references": [{ "path": "./packages/api" }, { "path": "./packages/web" }]
}
// CI: tsc --build --force   // 7.x uses parallel checking automatically
counter form: one tsconfig at the root that imports everything; a single package change triggers a full-tree check.
verification: Type-check wall-clock drops and only the changed project's .tsbuildinfo is rewritten; single-threaded mode available via the experimental flag for debugging.
