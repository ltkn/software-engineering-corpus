Goal: Turn an invalid-fields body into a field map without ever trusting its shape.
Typed form (passes both compilers):
export function fieldFaults(err: unknown): Record<string, string> {
  const faults: Record<string, string> = {};
  if (problemType(err) !== PROBLEM_TYPES.INVALID_FIELDS) return faults;
  const errors: unknown = (err as ApiError).problem?.errors;
  if (!Array.isArray(errors)) return faults;
  for (const f of errors as Array<Partial<FieldError>>) {
    if (f && typeof f.field === 'string' && typeof f.message === 'string') {
      faults[f.field] = f.message;
    }
  }
  return faults;
}
Why: unknown-first handling forces the Array check and the per-entry string checks, so a malformed errors array degrades to the detail line instead of a runtime crash. Returning an empty map for any other refusal keeps the caller branch-free.
Counter-form: casting problem.errors as FieldError[] and indexing [0] directly, which throws on a backend that sends errors as an object on one route; or any-typed faults that let a message object slip into the template.
